# Fridge Roast: One Line, Biggest Laugh

A [make.fun](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) bounty entry. `main.py` writes one line — at most 200 characters — roasting a smart fridge to `/output/entry.txt` and prints it.

## The entry

> My smart fridge updated itself at 3 a.m. and now beeps at my leftovers like a disappointed IT department.

## Run

```sh
python3 main.py
```
